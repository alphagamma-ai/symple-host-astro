## Recording Flow

1. Start on the Getting Started page.
2. Show the visual setup path.
3. Open the key first articles: account, workspace, Airbnb import, payments, calendar, and messages.
4. End with the idea that users should finish the first 24-hour path before optimizing advanced modules.

## 1-Minute Voiceover

"If you are new to SympleHost, start with the Getting Started path. The best sequence is simple: create your account, set up your workspace, then connect your first property. Most hosts connect Airbnb first, so use Airbnb Import to bring the listing into SympleHost, then add Booking.com, Expedia, Agoda, VRBO, and other OTAs through Channel Manager. Configure payments next, then check calendar, reservations, messages, and operations. Manual setup is mainly for direct-booking-only hosts. If you need to start with Booking.com, use Channel Manager and Channex. Follow this path first, then come back to the module videos when you are ready to improve each workflow."
