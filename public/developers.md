# SympleHost Developers

Build integrations against the SympleHost Partner API.

## Quickstart

1. Partner API HTML docs: /partner-api.html
2. OpenAPI: /openapi.json
3. Authenticate (Basic or HMAC-SHA256 for sensitive scopes)
4. Accept: application/vnd.symplehost.partner.v1+json
5. Paginate with meta.next_cursor

## Spec locations

- /openapi.json
- /api/openapi.json
- /partner-api/openapi.yaml
- /.well-known/api-catalog
