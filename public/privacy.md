# Privacy

This page describes privacy practices for the **SympleHost Knowledge Base** at help.symplehost.ai. The knowledge base is a public documentation site. It does not require an account to read articles, and it does not collect reservation, guest, or payment data through these pages.

## What this site collects

Standard web server and CDN logs may record IP address, user agent, requested URL, referrer, and approximate location for security, reliability, and traffic analysis. Site search runs in the browser against a static index.

## Cookies and analytics

The knowledge base is designed to work without mandatory marketing cookies. Any analytics tooling is limited to documentation usefulness and site health.

## Product and account data

Guest messages, calendars, payments, and property data are processed inside the SympleHost application (symplehost.ai), not on this help site. Product privacy terms govern account data and AI features.

## Contact

Privacy questions: support@symplehost.ai. See also https://help.symplehost.ai/contact
