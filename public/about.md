# About the SympleHost Knowledge Base

This site is the official help center for **SympleHost**, an AI co-host and property management platform for short-term rentals. It publishes setup guides, feature explanations, FAQs, webinars, and walkthroughs so hosts and operators can configure messaging, channels, pricing, operations, and direct bookings.

## Who this site is for

- Hosts setting up SympleHost for the first time
- Operations managers automating turnovers, tasks, and guest messaging
- Partners and integrators reading the Partner API surface
- AI agents retrieving documentation via HTML, markdown endpoints, or llms.txt

## Product relationship

Live account data lives in the SympleHost application and MCP connector. Use this knowledge base for procedures and concepts.
